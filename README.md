### 02 · [Simple CDN](https://github.com/Vivekkumarprince1/simple-cdn) — Regional C++17 Content Delivery Network
> **High-performance regional HTTP CDN with edge intelligence, GeoIP routing, and automated failover built in modern C++17.**
>
> 📁 **[Repository ↗](https://github.com/Vivekkumarprince1/simple-cdn)**

- **Edge Architecture:** Designed a regional CDN router orchestrating 3 independent edge server nodes (Delhi, Mumbai, Bengaluru) with health check heartbeats and circuit-breaking failover.
- **Network Optimization:** Implemented custom GeoIP-based routing, ETag cache validation, HTTP byte-range slicing for streaming, and bounded worker-pool multithreading.
- **Security & Observability:** Hardened against path-traversal attacks with trusted-proxy controls and built a real-time browser operations dashboard displaying node telemetry and routing metrics.
- **Tech Stack:** `C++17` · `HTTP Networking` · `GeoIP Routing` · `Multithreading` · `Edge Caching` · `Systems Design`

### 03 · [Vaani](https://github.com/Vivekkumarprince1/vaani) — Real-Time Multilingual Communication Platform
> **Ultra-low latency speech translation engine and WebRTC conference platform bridging conversations across 40+ languages.**
>
> 🔗 **[Live Demo ↗](https://react-vaani-frontend.vercel.app/login)** &nbsp;|&nbsp; 📁 **[Repository ↗](https://github.com/Vivekkumarprince1/vaani)**

- **Real-Time Translation Pipeline:** Engineered an end-to-end audio translation stream across **40+ language pairs** maintaining sub-**500ms** latency with Azure Speech & Translator SDKs.
- **Latency Reduction:** Slashed raw audio processing overhead by **4x (128ms → 32ms)** utilizing Voice Activity Detection (VAD) silence stripping and TTL-based LRU translation caches.
- **Signaling Layer:** Built an event-driven WebRTC signaling layer over Socket.IO for peer-to-peer and group calls with seamless JWT authentication and reconnect states.
- **Tech Stack:** `React.js` · `Node.js` · `Express` · `Socket.IO` · `WebRTC` · `Azure Speech SDK` · `MongoDB`
